What is User Activity?

System - User activity shows all audit information about one user in one place (an audit trail). It collects nothing new - it filters that user's entries out of every log table and the trash. The page is read-only: records cannot be edited or deleted.

  • Use it only for security and troubleshooting - it is not a tool for continuous monitoring of staff
  • Whose activity you viewed, and with which filters, is written to the access logs (user-activity-view)
  • Users are told that their actions are logged in the Terms of use (section 9) and the Privacy policy (References - Templates: tos, pp)

How to use

  1. Search the User field by name, username or email and pick one (deactivated users are listed too)
  2. Optionally choose an action type (Created, Updated, Deleted, Viewed, Sign-in / Act As - on the "Actions" tab only), a log table and a from / to date, then click the filter button
  3. Pick a tab (table below). Rows are newest first: date, table, message, action
  4. Click a row to open its full context (IP, browser, old / new values of changed fields, etc.)
  5. When there are more than 50 rows, a Load more button appears
TabWhat it shows
ActionsEverything the user did - from every log table. Actions made in Act As mode carry an Act As badge
Done to the userChanges made to this user's account: profile edits, roles and organizations granted / removed, activation / deactivation - with who made them
Sign-insSign-ins, sign-outs, organization switches, and failed attempts with this username (to spot password guessing)
Emails receivedEmails the system sent to the user's address (To / Cc / Bcc) and whether they were delivered to the transport
Deleted recordsRecords the user deleted (Trash). The log table filter does not apply here

Auditing an organization

Click By organization at the top to list the actions of every member of one organization (like the "Organization audit log" of GitHub or Google Workspace). Each row shows who did it in a blue badge.

  • Pick the Organization - any organization when signed in to the system organization, otherwise your active organization (fixed)
  • The User is optional - picking one shows only that person's actions in the organization; the x on the badge clears it
  • An entry belongs to the organization of the record (record_organization_id) when it is logged, otherwise to the organization the actor was signed in to - so system staff working on that organization's records show up here too
  • Entries logged without an organization are not included: public website actions (contact form, sign-up) and successful sign-ins; actions on global content (news, pages, products) count for the actor's organization
  • Only the "Actions" tab works in this mode

CSV export

  • The CSV button downloads what the current mode, tab and filters return - at most 10000 rows (newest first). For more, split the export by date range
  • Columns: date, table, level, action, message, record id, record organization, user, signed-in organization, Act As, IP, browser, full context (JSON)
  • UTF-8 with BOM so Cyrillic opens correctly in Excel. Cells starting with "=", "+", "-", "@" get a leading "'" so they never run as formulas
  • Every export is written to the access logs (user-activity-export, with the row count)

Organization scope

  • Signed in to the system organization (or a system_coder): every user and every record
  • Signed in to another organization:
    • only that organization's members can be selected, and system_coder users are not listed
    • the "Actions" and "Done to the user" tabs only show actions made while signed in to that organization
    • the "Sign-ins" tab only shows switches into that organization, sign-outs from it and failed sign-in attempts
    • the "Emails received" and "Deleted records" tabs are hidden - emails and the trash carry no organization, so this keeps the user's other organizations' data from leaking
